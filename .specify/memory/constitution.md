# Конституция Stagehand Jev experiment

Версия: 1.0.0. Принята и обновлена: 2026-11-03.

1. **Честные результаты.** Разделять реализованный код, unit/contract проверки, browser E2E и живой model benchmark. Неизвестные метрики не заменять нулями. Не заявлять ускорение без измерений.
2. **Ограниченный выбор.** DOM/AX уплотняется детерминированно без обычной LLM для preselection. Провайдер выбирает допустимый ID/none; приложение владеет действием, значениями и postcondition.
3. **Fail closed.** Проверять цель заново, не повторять неопределённое действие, не переключать модель/endpoint/тариф скрыто. Успешный клик не равен успешной задаче.
4. **Расходы и приватность.** Общий потолок задачи $1; отсутствие подтверждённого контроля означает blocked. Секреты не сохраняются в репозитории; evidence остаётся локальным. Никаких бронирований и платежей.
5. **Сопоставимость.** Baseline и enhanced выполняют одинаковые сценарии и assertions. DeepSeek V4.1 Flash через OpenCode является целевым baseline; подготовка протокола не считается live validation.
6. **Сохранение upstream.** Не менять исходный act и лицензию Stagehand ради эксперимента. Изменения публикуются только в разрешённый fork/feature branch. Не возобновлять остановленный локальный запуск без указания пользователя.

Изменения этих принципов требуют явного review; планы и задачи обязаны отмечать отступления и доказательства проверки.
